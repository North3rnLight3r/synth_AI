# ForgeSynth Plugin Architecture
## Core Components

1. **AudioProcessor**: Handles the MIDI input and the audio buffer loop.
2. **NeuralEngine**: A C++ wrapper for ONNX Runtime that loads the `.onnx` model.
3. **WavetableOscillator**: Uses the buffers generated by the NeuralEngine.
4. **OmniGUI**: A JUCE-based interface utilizing OpenGL for real-time latent space visualization.

## Data Flow
MIDI Key -> Latent Mapping -> ONNX Runtime Inference -> Wavetable Buffer -> Low Pass Filter -> Output
